## 🛠️ 2. Архитектура и реализованные технологии

Сайт реализован по стандартам современного веба **без тяжёлых внешних фреймворков и библиотек**, на чистых и производительных нативных Web APIs:

### 2.1. Режимы зрения и интерактивный свет
- **Динамический фонарь на Canvas:** холст `#flashlight-canvas` рисует луч света фонаря, следующий за курсором мыши со сглаживанием (LERP). Яркость луча и охват увеличены на +20%. При скролле вниз свет мягко адаптируется для комфортного чтения текста.
- **3 режима камеры:**
  1. `NORMAL` — нейтральный направленный луч света.
  2. `NVG` (Ночное видение, по умолчанию) — зеленый фосфорный спектр с эффектом сканирующих линий.
  3. `VHS REC` — эффект винтажной аналоговой плёнки с процедурными помехами (10–40% шума и горизонтальных артефактов).
- **Автосмена режимов:** каждые 20 секунд происходит переключение на следующий режим. При ручном выборе режима автосмена ставится на паузу на 1 минуту.
- **Native View Transitions API:** переключение режимов зрения выполняется через нативный браузерный API плавного перехода (`document.startViewTransition`).

### 2.2. Процедурный звук (Web Audio API)
- **Авто-воспроизведение при первом контакте:** запуск бинаурального низкочастотного дрона (48 Гц и 51.5 Гц через Lowpass-фильтр 180 Гц).
- **Плавное «дыхание» громкости (от 10% до 60%):** громкость звука циклически модулируется синусоидой с периодом 60 секунд (от 10% до 60% от базового уровня `0.12`).
- **Связь дрожания текста с громкостью:**
  - Заглавные буквы текста при наведении мыши притягиваются магнитом (сила 20–40 px).
  - После отпускания буквы дрожат 5 секунд.
  - **Амплитуда дрожания строго пропорциональна текущей громкости аудио!**
  - При отключении звука (`AUDIO: OFF` / Mute) дрожание букв не исчезает полностью, а остаётся на деликатном уровне **10%**.

### 2.3. Живая телеметрия в видоискателе (HUD)
- **Реальное системное время (`HH:MM:SS:FF`):** отображает текущее настенное время устройства с миллисекундами/кадрами, обновляемое через Temporal API с фолбэком на Date.
- **Реальное адаптивное разрешение:** алгоритм определяет фактическое физическое разрешение экрана (или окна) с учетом ориентации (портрет/альбом) и подбирает точное стандартное название:
  - ПК/Монитор: `QHD` (2560×1440), `FHD` (1920×1080), `4K UHD` (3840×2160), `UWQHD` (3440×1440) и др.
  - Смартфоны: `FHD+` (2400×1080 / 2340×1080), `Super Retina` (iPhone), `HD+` (1600×720) и др.
- **Реальный счётчик кадров (FPS):** живое измерение кадровой частоты браузера через `requestAnimationFrame` (отображает честные 60, 120, 144 FPS).
- **Режим «RAW»:** индикатор формата сырой видеозаписи кинокамеры.

### 2.4. Пасхалка-скример (Easter Egg Screamer)
- **Условие активации:** если увести мышь в крайний левый или правый край экрана (10% ширины) и не двигать ничего в течение **15 секунд**.
- **Поведение:**
  1. Звучит резкая пронзительная сирена на **100% громкости** ровно **5 секунд**, затем плавно спадает за 2 секунды до тишины.
  2. Выезжает яркая **кислотно-жёлтая 3D-плашка** с полосами опасности:
     - Если мышь в нижней половине — плашка выезжает **вверху**.
     - Если мышь в верхней половине — плашка выезжает **внизу**.
     - Плашка зафиксирована (`position: fixed`) и **не двигается по вертикали при скролле**.
  3. Текст на лицевой стороне: **«НЕ ОСТАНАВЛИВАЙСЯ!!!»**.
  4. Через 5 секунд плашка делает 3D-переворот вдоль вертикальной оси на $180^\circ$, с обратной стороны надпись: **«УВИДЕМСЯ !!!»**.
  5. Спустя 10 секунд после переворота плашка плавно заезжает обратно в край экрана.

## 🚀 4. Как запускать и редактировать сайт

### Локальный запуск:
Сайт полностью статичен, его можно открыть прямо в браузере или через любой локальный веб-сервер:
```powershell
# Вариант через Python:
cd docs
python -m http.server 8000
# Открыть в браузере: http://localhost:8000
```
Либо через расширение **Live Server** в VS Code.

### Публикация изменений на GitHub Pages:
Все файлы сайта лежат в папке `docs/` ветки `main`. Как только ты делаешь `git push origin main`, GitHub автоматически обновляет сайт по адресу:
👉 **https://riventstudio.github.io/STOLEN-PEACE/**

Команды для обновления сайта:
```bash
git add docs/
git commit -m "feat: обновление описания или добавление новых скриншотов"
git push origin main
```
