C# Interface 01

IInteractable Pattern

Единый контракт взаимодействия с объектами мира. Любая дверь, замок, записка или выключатель реализуют интерфейс с поддержкой физического луча и проверки условий. 

public interface IInteractable {
    void OnHover();
    void Interact(PlayerController player);

}
