# STOLEN PEACE — сторонние ассеты

Этот открытый репозиторий не должен распространять исходники сторонних Unity-ассетов.

## Не публикуются

- `Assets/HOUSE/` — набор импортированных моделей, текстур, префабов и демо-сцен от разных авторов.
- `Assets/ALP_Assets/` — импортированный пакет растительности.
- `Assets/QA_Books/` — сторонний пакет книг; локальный README содержит указание на покупку пакета.
- `Assets/Real Stars Skybox/` — сторонний пакет skybox.
- `Assets/New Solution Studio/` — сторонний PBR Lamps Pack.
- `Assets/Scenes/ZNS3D/` — сторонний Vintage Living Room Game Pack.
- `Assets/FPS/KinematicCharacterController/` — внешний контроллер персонажа; локального файла лицензии не найдено, поэтому публичное распространение исходников не предполагается.

## Что остаётся в публичной части проекта

Публичная история предназначена для собственных сцен, собственных C#-скриптов, настроек Unity и проектной конфигурации STOLEN PEACE.

Для полного визуального восстановления проекта сторонние ассеты должны быть получены из их исходных источников и импортированы отдельно.

Удаление из Git не означает удаление с MSI: локальные копии сторонних ассетов остаются в рабочем Unity-проекте.
